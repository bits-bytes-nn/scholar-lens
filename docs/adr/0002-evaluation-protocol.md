# 0002. 평가 절차: 가린 판정, 독립 세션, 고정 말뭉치, 생성 쌍

- 상태: 채택
- 관련: `docs/engine.md` 1.3절, 7장, `docs/redesign.md` 7장

## 배경

이전 평가의 "3회 판정"은 한 세션에서 나와 서로 독립적이지 않았고, 개발용과 확인용 항목이 나뉘지 않았습니다. 판정 편차(F에서 평균 1.2점)보다 작은 차이로 기본값을 바꾼 경우도 있었습니다.

## 결정

- **가린 판정**: 비교하는 두 글을 X·Y로 가리고, 판정자는 어느 엔진이나 설정에서 나왔는지 모릅니다.
- **독립 세션**: 판정마다 새 세션을 씁니다. 한 세션에서 여러 번 판정한 결과는 한 번으로 셉니다.
- **고정 말뭉치**: 비교하는 설정은 같은 수집 자료 저장본(`tech_guide.source_snapshot_ttl_days`, 논문 본문)에서 생성합니다. 수집 차이가 품질 차이로 섞이지 않게 합니다.
- **생성 쌍**: 설정마다 2회 생성해 생성 편차를 함께 봅니다.
- **평가셋 분리**: 개발용 항목으로 고치고, 기본값 변경은 확인용 항목으로 판단합니다.
- **채택 기준**: 차이가 잡음의 2배 이상일 때만 채택합니다. 결정적 지표(반복률, 규칙 위반, 근거 없는 문장 수, 단계별 토큰·비용)를 판정 점수보다 앞에 둡니다.

## 결과

- 평가 한 번의 비용이 늘지만, 판정 편차 안의 차이로 기본값을 바꾸는 일을 막습니다.
- 평가 실행 기록은 `eval/runs/`에 두고, 결과 요약은 `docs/redesign.md`에 남깁니다.
