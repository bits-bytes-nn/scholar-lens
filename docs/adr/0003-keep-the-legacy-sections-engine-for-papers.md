# 0003. 리뷰·요약은 근거 장부 엔진이 가린 비교에서 이길 때까지 이전 엔진을 기본으로 둔다

- 상태: 채택(현재 유지 중)
- 관련: `docs/engine.md` 1.2절, 8장 E9, `explanation.engine`, `summary.engine`

## 배경

가이드와 서베이는 근거 장부 엔진만 씁니다. 리뷰와 요약은 이전 엔진(`sections`, `scholar_lens/legacy/`)이 기본이고 근거 장부 엔진(`evidence`)은 선택 사항입니다. 설정 일부는 두 엔진 중 한쪽에서만 동작합니다.

## 결정

- 리뷰·요약의 기본 엔진은 `sections`로 둡니다.
- 근거 장부 엔진이 ADR 0002의 절차로 확인용 항목에서 이전 엔진 이상이라고 판정될 때 기본값을 바꾸고, `legacy/`와 전용 설정을 지웁니다.

## 현재 상태

- 최근 가린 비교에서 근거 장부 엔진은 논문 4쌍 모두 충분성에서 졌습니다. 판정자는 방법 절, 정리, 주요 결과의 누락을 지적했습니다.
- 원인으로 확인된 읽기 단계의 결함(핵심 대상만 기록하고 멈추는 읽기 지시, 근거 개수가 범위 아래일 때의 재요청 부재)은 고쳤습니다. 기본값 변경 여부는 다시 평가한 뒤 정합니다.

## 결과

- 두 엔진을 함께 유지하는 비용(설정, 테스트, 문서)이 남습니다.
- 삭제 기준이 평가 결과로 정해져 있어, 엔진 교체가 품질 후퇴로 이어지지 않습니다.
